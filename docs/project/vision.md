# Vision

Make consequential reasoning easier to inspect, falsify, revise, and safely hand off without
confusing stronger analysis with expanded authority.

COMPASS-C should remain modular and local-first: hosts may use the guidance alone, run bounded
calculations, retain a task-owned record, or expose the same operations through an adapter. Every
layer must preserve provenance, uncertainty, reversal conditions, and honest proof boundaries.

## Product horizons

The target is stronger decisions and earlier correction, not more calculators or a
universal autonomous platform. Horizons are outcome ambitions, not release promises:

- **v1 — trustworthy decision instrument:** inspectable briefs, sensitivity,
  compatible records, directly verified client paths and measured usefulness.
- **v2 — living decisions:** opt-in evidence updates, dependency invalidation,
  reversal conditions and outcome review without silently rewriting history.
- **v3 — coordinated decisions:** shared constraints, sequencing, option value and
  preserved disagreement across a portfolio; external owners retain authority.
- **v4 — experimental decision partner:** identify decision-changing uncertainty,
  propose bounded informative experiments and revise models from observed results.

COMPASS supplies framing, comparison, probing and self-correction. Specialist skills
and DSPy programs retain domain work, such as source-faithful paragraph reading.
A reader's puzzle/purpose can guide which evidence matters without replacing the
source's meaning or granting authority to adopt its conclusions.

## First-consumer skill and learning adoption

Prioritize useful standalone COMPASS-C and its repo-owned skill quality before
requiring the whole AI Society foundry. Apply agent-skill-engineer to bounded,
recurring workflows; use KES evidence to propose causal improvements and recipient
review to accept or withdraw them. A skill is not warranted merely because a repo
exists. Types, validators and tests should own deterministic requirements.

The first consumer is this repository. Wider adoption must preserve each repo's
ownership, negative routing cases, evidence thresholds and privacy scopes. No global
skill duplication, template rollout or automatic learning follows from local success.

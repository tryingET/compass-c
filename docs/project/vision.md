# Vision

Make consequential reasoning easier to inspect, falsify, revise, and safely hand off without
confusing stronger analysis with expanded authority.

COMPASS-C should remain modular and local-first: hosts may use the guidance alone, run bounded
calculations, retain a task-owned record, or expose the same operations through an adapter. Every
layer must preserve provenance, uncertainty, reversal conditions, and honest proof boundaries.

# Mission

Ship a compact Agent Skill and dependable Python toolkit that help people and agents compare
alternatives, test decisive assumptions, trace higher-order effects, and reconsider conclusions
when evidence changes.

Prefer deterministic enforcement for storage, calculation, packaging, and verification. Keep
open-ended judgment in the skill. Never let either layer claim authority it does not possess.

# System4D — Compass

## Driver

Enable decisions that are explicit about evidence, uncertainty, consequences, reversal
conditions, and authority boundaries.

## Outcomes

- A user receives a proportional, conditional recommendation rather than a framework transcript.
- Decisive calculations are reproducible and scoped to their assumptions.
- Persisted evidence can be invalidated without erasing history.
- Generated skills and archives stay tied to one canonical implementation.
- Status language distinguishes local proof from host behavior, installation, and permission.
